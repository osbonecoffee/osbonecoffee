# Os Bone Coffee — Paket Online

Versi ini siap di-host di **GitHub Pages** dengan **Google Sheets sebagai database melalui Google Apps Script**.

Template dan desain aplikasi dipertahankan. File `index.html` ditambahkan sebagai entry point GitHub Pages tanpa menghapus `1-Website-Utama.html`.

Baca `SETUP-GITHUB-GOOGLESHEETS.md` untuk langkah instalasi.
